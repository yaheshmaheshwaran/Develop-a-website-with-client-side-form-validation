## 📋 Project 1 — Client-Side Form Validation

**Tech:** HTML5, CSS3, Vanilla JavaScript

### Features
- ✅ 6 validated fields: Name, Username, Email, Phone, Password, Confirm Password
- ✅ Real-time field validation on input + blur
- ✅ Password strength meter (5 levels)
- ✅ Show/hide password toggle
- ✅ Shake animation on invalid submission
- ✅ Terms & Conditions checkbox validation
- ✅ Simulated async form submission with loader
- ✅ Success screen with reset
- ✅ Glassmorphism dark UI with animated background orbs

### How to Run
Simply open `index.html` in a browser. No server needed.
